# our-games

Сайт с нашими играми. Каждая игра лежит в своей папке внутри `games/`.

## Как добавить свою игру

1. Скопируйте папку `template` в `games/` и назовите её латиницей без пробелов, например `games/anya-platformer`.
2. Откройте `games/anya-platformer/index.html` и напишите там свою игру (пример внутри можно удалить).
3. Откройте `games.js`, скопируйте блок `{ ... }` и поменяйте название, автора, описание, эмодзи, цвет и путь.
4. В GitHub Desktop: Commit, затем Push. Через минуту игра появится на сайте.

Перед работой нажимайте Fetch origin и Pull, чтобы получить чужие изменения.
